- **Sources are third-party mirrors, not canonical editions.** sanskritdocuments.org returned 403, so text came from sa/hi.wikisource (raw wikitext or API), GitHub mirrors (bhavykhatri/DharmicData, sanskrit/raw_etexts Gita Press HTML and Peter Freund e-texts, TheHardikDewra/durga-saptashati, kaustubhk24/sangrah, jayeshmepani/HinduScriptures). Every raw file is in `texts/raw/`.
- **Ramcharitmanas (7 kands, 6271 verses) and Bhagavad Gita (701 verses)** are passed through verbatim from DharmicData; only punctuation/markers are cleaned. Only the opening chaupai of Balkand and Gita 1.1 were cross-checked against a second source. The Gita per-chapter verse counts match the standard 701.
- **Ramcharitmanas single-line verses**: some chaupai blocks have an odd number of lines in the source (a lone chaupai line before a doha), so a few verses are one line. This is how the source is laid out, not a parsing slip.
- **Durga Saptashati (13 chapters, 602 verses)** is the numbered-mantra text only. Speaker lines ("ऋषिरुवाच" etc.), chapter colophons and dhyana/vinyoga headers are dropped, and some mantra ranges are merged by the source, so the count is below the traditional 700. The Devanagari in the source was generated from the proofread sanskritdocuments `durga700.itx`; an ITRANS artefact ("।ह्" inside conjuncts) is repaired by the build script.
- **Navagraha (station 11)** verses are one stotra shloka per graha from sa.wikisource, not bija mantras. If you want bija mantras (e.g. "ॐ ह्रां ह्रीं ह्रौं सः सूर्याय नमः"), they need a separate fetched source.
- **Mahamrityunjaya** is Rigveda 7.59.12 from DharmicData with accents removed. The kaustubhk24 page has the typo "मृक्षीय" (the Rigveda has "मुक्षीय") and writes "ओं"; the library prefixes "ॐ" to match common recitation.
- **Vakratunda** uses the Gita Press variant "कोटिसूर्यसमप्रभ". Gathering ganesh/durga come from the Gita Press Satyanarayan page, shiv (Karpura Gauram) from Gita Press arati-sangrah.
- **Sundarkand under Hanuman** is not repeated, because it is already station 6 (Ram, Sundarkand is kand 5).
- **Spelling editions differ between sources.** Spot-check "DIFFERS" rows are spelling/edition differences, not wrong verses: Rudrashtakam (नमामीशमीशान vs नमामिशमीशान), Hanuman Chalisa (बरनउँ vs बरनऊं, and the other source holds more lines), Gayatri (second source drops the visarga in "यो नः"), Mahamrityunjaya (see above), Sri Suktam (second source has "हिरण्यवर्णाम" and "आवह" for "म आ वह").
- **Punctuation is normalised.** ASCII and curly punctuation and all parenthetical glosses are removed; only danda and double danda remain. Over-long verses (over 400 characters) are split at line boundaries.
- **A human should double-check**: Lakshmi Chalisa verse 2 (the "टेक" refrain label was removed), Shiv Chalisa verses 22-24 (closing doha grouping), and any Ramcharitmanas verse a reciter knows well; the Ramcharitmanas text has not been proofread beyond the single spot check.
